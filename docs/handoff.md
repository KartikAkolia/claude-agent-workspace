Fixed with a longest-overlap-against-everything-emitted-so-far algorithm instead, which correctly collapsed to 49,120 clean, non-duplicated words — verified by eye against both the start and end of the real transcript.
3. **Windowing** — same ~90-minute-window pattern as the Gemini script, but the reason differs: here it's to keep each single Claude generation's expected output short enough not to truncate, not an input-size limit (Claude's context comfortably holds the whole transcript).
4. **Generation via headless `claude -p`** — each window/merge/chapters call shells out to `claude -p --tools "" --no-session-persistence --output-format text --strict-mcp-config` (the last flag added after a first test leaked a `Client.listTools()... server does not advertise tools capability` diagnostic line into the saved output; suppressed it cleanly).
