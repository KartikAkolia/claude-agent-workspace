### This session's work (2026-10-24, on the CachyOS laptop): device power saving turned off, install and reboot pending

Kartik asked to turn off USB autosuspend, PCI runtime power management, and runtime suspend of the NVIDIA dGPU. He chose to keep system suspend, hibernate and lid handling as they are. Before the change, `usbcore` autosuspend was `2`, most USB and PCI devices had `power/control` set to `auto`, the ASPM policy was `default`, NVMe `default_ps_max_latency_us` was `100000`, `snd_hda_intel` `power_save` was `10`, `wlp2s0` reported `Power save: on`, and the NVIDIA driver had `DynamicPowerManagement: 3`. This session has no sudo, so nothing on the system has changed yet. `scripts/disable-device-power-saving.sh` contains the full change; its header lists the files it installs and how to undo them. The GRUB edit was tested on a scratch copy of `/etc/default/grub`, and a second run did not add the parameters twice.

1. **Run by Kartik:** `scripts/disable-device-power-saving.sh`, from a real terminal. It installs a udev rule, a `modprobe.d` file and a NetworkManager drop-in, adds `usbcore.autosuspend=-1 pcie_aspm.policy=performance nvme_core.default_ps_max_latency_us=0` to `GRUB_CMDLINE_LINUX_DEFAULT` (a backup is saved as `/etc/default/grub.bak-nopm`), reruns `grub-mkconfig` and `mkinitcpio -P`, and applies whatever it can to the running system.
2. **Reboot, then verify:** `cat /proc/cmdline` should include all three new parameters. `cat /sys/module/usbcore/parameters/autosuspend` should print `-1`. `grep -L '^on$' /sys/bus/usb/devices/*/power/control /sys/bus/pci/devices/*/power/control` should print nothing. `cat /sys/module/pcie_aspm/parameters/policy` should show `[performance]`. `cat /sys/module/nvme_core/parameters/default_ps_max_latency_us` should print `0`. `grep Dynamic /proc/driver/nvidia/params` should show `DynamicPowerManagement: 0`. `cat /sys/bus/pci/devices/0000:01:00.0/power/runtime_status` should print `active`. `cat /sys/module/snd_hda_intel/parameters/power_save` should print `0`. `iw dev wlp2s0 get power_save` should print `Power save: off`. Until that reboot, persistence has only been checked by reading the config.
