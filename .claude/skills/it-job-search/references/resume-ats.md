# Resume, LinkedIn & ATS Optimization

Sourced per `docs/personal-research-guidelines.md`. Two source types here: LinkedIn's own
official career-advice content (primary source on how LinkedIn itself expects a profile
to look), and Jobscan (an established vendor whose product is literally ATS-matching —
treated as a reputable industry source, not treated as neutral/unbiased on "buy our
scanner," so the mechanics below are kept, the upsell isn't).

## What actually is an ATS, and what it does (source: Jobscan, "How to Write an ATS
Resume That Gets Past the Bots," and Jobscan's State of the Job Search 2026 report)

- Fact: 99.7% of recruiters (per Jobscan's own survey data — self-reported by the vendor,
  flag as vendor-sourced rather than independently audited) use keyword filters in their
  ATS to sort/prioritize applicants before a human reads the resume.
- Fact: many ATS platforms don't just keyword-match — they compare the whole resume
  against the job description (experience, education, skills) and produce a match score
  recruiters sort by.
- Fact: Workday is, as of 2026, the most widely used ATS among Fortune 500 companies —
  worth checking which ATS a specific employer uses if that's discoverable, since parsing
  rules differ by platform.
- Analysis (Jobscan's stated guidance, reasonable but not an independently-verified
  claim): a ~75% keyword match rate is a reasonable target; many candidates succeed at
  ~65%; pushing much past 75% usually means keyword-stuffing, which reads badly to the
  human who eventually opens it. Match rate is a proxy, not the goal — don't optimize the
  resume into something dishonest or unreadable to chase a number.
- Fact: one Jobscan data point — resumes using the job posting's exact title had 10.6x
  higher reported interview likelihood than resumes that paraphrased it. Treat as a
  strong, specific, low-cost thing to actually do (put the target title in the resume
  summary/header if it's honestly true of the role), not as license to lie about title
  history.
- Source: <https://www.jobscan.co/blog/ats-resume/>

## Formatting mechanics that affect ATS parsing (source: Jobscan)

- Use both the long-form and acronym version of a keyword at least once (e.g., "Certified
  Information Systems Security Professional (CISSP)"), since the ATS or the recruiter's
  own search may use either.
- Chronological or hybrid format, not purely functional/skills-first — ATS parsers and
  recruiters both expect a work-history timeline.
- Avoid tables, columns, and text boxes/graphics — many parsers read these incorrectly or
  drop them entirely.
- Use a standard, screen-readable font; avoid putting contact info or content in
  headers/footers, since some parsers skip those regions.
- Source: <https://www.jobscan.co/blog/ats-resume/>

## Content and human-reader mechanics (source: LinkedIn's own career-advice content,
"Resume Tips for New Graduates and Experienced Professionals," and LinkedIn's Talent
Blog guidance on recruiter attention)

- Fact (LinkedIn's own framing): recruiters reportedly give a resume roughly 7.4 seconds
  of initial attention — treat this as directional, not a precise measured constant, but
  it supports the underlying point: the top third of the resume has to establish fit
  immediately.
- Fact: LinkedIn explicitly recommends the resume's work history match the LinkedIn
  profile's work history — a mismatch reads as a red flag to a recruiter cross-checking
  both.
- Fact: margins should stay ≥0.8in, font ≥11pt, per LinkedIn's own formatting guidance.
- Fact: one-page is no longer treated as a hard rule; length should track relevant
  experience, not an arbitrary constraint.
- Guidance (accomplishment framing, widely used, attributed as career-coaching practice
  rather than a single authoritative citation): turn responsibilities into accomplishment
  statements — "accomplished [X] by doing [Y], which resulted in [Z]" — with a real,
  ideally quantified [Z]. Don't fabricate the quantity; if the user doesn't have a real
  number, use a truthful qualitative outcome instead of inventing a metric.
- Source: <https://www.linkedin.com/top-content/career/resume-tips/resume-tips-for-new-graduates-and-experienced-professionals/>

## IT/tech-specific signal

- Certifications in cloud platforms, cybersecurity frameworks, and AI/ML tooling carry
  particular weight in tech hiring right now (cross-reference against
  `references/role-requirements.md` for which certs actually map to the user's target
  role — don't recommend certs generically).
- An active, current LinkedIn profile (recent posts/comments/engagement) is treated by
  recruiters using LinkedIn's own sourcing tools as a freshness/engagement signal — a
  static profile is a weaker search hit than an active one, independent of resume quality.

## Non-negotiable when applying any of this

Never write a resume or LinkedIn claim the user hasn't confirmed is true. This skill
tailors phrasing, keyword coverage, and emphasis to a specific posting — it does not
invent experience, credentials, or metrics. If the user's actual background is a weak
match for a target posting, say so plainly rather than papering over the gap.
